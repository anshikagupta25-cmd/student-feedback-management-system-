# Student Feedback Management System

## Project Overview

The Student Feedback Management System is a Python-based application developed
to collect, store and manage feedback provided by students.

The project uses CSV files for storing student details, subject information,
advisor information and feedback records. The system provides a
menu-driven interface for performing different feedback management tasks.

## Objectives

- To develop a simple student feedback management system.
- To collect and store student feedback.
- To manage student information.
- To manage subject and advisor information.
- To provide feedback searching and viewing features.
- To calculate average feedback ratings.
- To demonstrate the practical use of Python programming concepts.

## Technologies Used

- Python
- CSV File Handling
- Visual Studio Code
- GitHub

## Main Features

- Student management
- Subject management
- Advisor management
- Student feedback submission
- View feedback
- Search feedback
- Subject-wise feedback
- Student feedback history
- Average rating calculation
- CSV-based data storage
